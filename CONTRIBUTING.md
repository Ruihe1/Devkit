# Contributing to DevKit

1. Fork the repo and create a branch.
2. Add your tool as an object in the `TOOLS` array in `index.html` (see the Hash tool for a small example).
3. Add its icon and description to the `META` object.
4. Use plain JavaScript with no external libraries.
5. Open a pull request describing the tool and how you tested it.

Good first issues: see the Roadmap in the README.
